Timing Functions

Simple put, the time function is the rate at wich the speed of the transitoin changes.

Linear

A linear transition moves at a steady rate from beginning to end.


Ease-in

This function begins slowly and accelerates towards the end of the transition.


Ease-out

Is the oppsite of ease-in. It stars fast and slows down toward the end of the transition.


Ease-in-out

Ease-ion-out is acombination of both the ease-in and ease-out functions. It begins slowly, accelerates through the middle part of the transition, then slows toward the end.

Transitions and JavaScript

Add or remove classes

Since the power of transitions is to animate between two states, we can create those states as separate classes. Then we add or remove these classes using JavaScript. Like so.

The example consist of a button and a content div. Initially the conten container has the class hide. In CSS, the hide class gives it a opacity of 0.

We also have a second class in the CSS called show. This class has an opacity of 1. When the button is clicked, we toggle the class of the div between hide and show. To give it animation, we apply a transition to the div also.
